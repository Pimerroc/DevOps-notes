(при создании юзера, можно указать дефолтную оболочку в виде -s /bin/bash к примеру в противном случае придется 
sudo chsh -s /bin/bash max)
Иногда обязательно необходимо добавить authorized_keys в ~/.ssh/
чтобы заходить без пароля по публичному ключу. Для этого можно использовать утилиту scp (secure cp) синтаксис такой же как у cp долько добавлять надо еще и ssh сервер
```bash
scp -P 22222 .ssh/id_rsa.pub max@127.0.0.1:~/.ssh/
```
или же 
```bash
ssh-copy-id -p 22222 max@127.0.0.1 
```
(лучше, потому как не надо делать все мануально)

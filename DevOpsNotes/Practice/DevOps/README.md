# Practice / DevOps

> [!summary] Лабораторные и проекты. Каждая лабораторная должна иметь цель, стенд, шаги, критерии успеха, cleanup и разбор.

## Правила

- Опасные эксперименты — только в VM/контейнерах.
- Для облака — временные ресурсы и `destroy` после лабораторной.
- Для Kubernetes — kind/k3d или k3s на VPS.
- Секреты — только через переменные окружения или локальный vault, не в git.
- В конце — отчёт по шаблону `Templates/DevOps Lab.md`.
- Все команды и версии проверяются, результат фиксируется в заметке.

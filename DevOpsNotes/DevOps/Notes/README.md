# Notes

> [!summary] Тематические заметки по доменам. Одна заметка — одна тема. Перед созданием ищи дубликаты.

## Домены

- `Linux/` — ядро, systemd, cgroups, namespaces, FS, процессы.
- `Networking/` — TCP/IP, DNS, HTTP/TLS, routing, NAT, tcpdump.
- `Containers/` — namespaces, cgroups, overlayfs, runc/containerd, Docker.
- `Kubernetes/` — control plane, objects, networking, storage, Helm, troubleshooting.
- `IaC/` — Terraform/OpenTofu, Ansible, state, modules, idempotency.
- `CI-CD/` — GitHub Actions, GitLab CI, pipelines, secrets, deployment strategies.
- `Observability/` — Prometheus, Grafana, Loki, OTel, SLO, alerts.
- `Security/` — secrets, supply chain, RBAC, NetworkPolicy, scanning.

## Правила

- Имя файла — тема, без даты.
- Frontmatter обязателен.
- Ссылки на связанные заметки — в конце.
- Блок `> [!check] Проверено` обязателен для технических утверждений.

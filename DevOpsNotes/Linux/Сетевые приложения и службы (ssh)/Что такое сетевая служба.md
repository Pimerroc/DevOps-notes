Сетевая службой называется программа, которая ожидает подключения или запросы от других компьютеров по сети и выполняет определённую работу.

В общем виде работа службы выглядит так:

```
Клиент
   │
   │ сетевое соединение / запрос
   ▼
Сетевой интерфейс
   │
   ▼
Ядро Linux
   │
   ▼
Сокет
   │
   ▼
Серверная программа
```

Сервер обычно:

1. создаёт сетевой сокет;
2. связывает его с адресом и портом;
3. начинает ожидать подключения или данных;
4. принимает запрос;
5. создаёт или передаёт обработчику соединение;
6. обрабатывает запрос клиента.

Для TCP-сервера важным этапом является ожидание соединений. После установления соединения сервер может обрабатывать конкретного клиента отдельно от механизма ожидания новых подключений.

Сетевые службы могут работать как:

- автономные серверы;
- службы, запускаемые по требованию.

Ранее для запуска сетевых служб по требованию широко использовались:

```
inetd
xinetd
```

Позднее эту роль во многих системах стали выполнять механизмы `systemd`, включая сокет-юниты.

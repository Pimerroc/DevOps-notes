## Назначение NFS

**NFS (Network File System)** — одна из наиболее распространённых систем совместного доступа к файлам в Unix-системах.

Она предназначена для подключения удалённых файловых систем.

В книге NFS рассматривается как подходящий вариант для:

```
крупных файловых систем
на сетевом накопителе или сервере
в надёжной локальной сети
```

---

## Особенности NFS

Существуют различные версии NFS.

NFS может работать через:

```
TCP
UDP
```

Также существуют различные параметры:

- аутентификации;
- шифрования;
- безопасности.

Книга подчёркивает, что многие механизмы защиты исторически не включены по умолчанию, поэтому безопасность NFS необходимо рассматривать отдельно.

---

## Монтирование

Базовый синтаксис:

```
mount -t nfs server:directory mountpoint
```

То есть:

```
server:directory
        ↓
   mountpoint
```

Технически:

```
-t nfs
```

может быть не нужен, поскольку `mount` способен определить тип самостоятельно.

---

## Безопасность

Параметр:

```
sec
```

предоставляет различные варианты обеспечения безопасности.

В небольших закрытых сетях администраторы могут использовать управление доступом на основе хоста.

Более сложные варианты, например:

```
Kerberos
```

требуют дополнительной настройки других частей системы.

---

## Автоматическое монтирование

При активной работе с сетевыми файловыми системами полезно использовать автомонтирование.

Это позволяет монтировать файловую систему только тогда, когда она действительно используется, и уменьшает проблемы с зависимостями при загрузке.

Исторически использовались:

```
automount
amd
```

Большая часть соответствующих задач теперь может выполняться с помощью юнитов:

```
systemd automount
```

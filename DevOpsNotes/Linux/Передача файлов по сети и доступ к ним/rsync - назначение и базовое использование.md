## Что такое `rsync`

`rsync` используется для передачи и синхронизации файлов.

По синтаксису он может напоминать:

```
scp
```

Например:

```
rsync file1 file2 ... host:
```

В современных системах `rsync` предполагает использование SSH для подключения к удалённому хосту.

Если имя пользователя отличается:

```
rsync file1 file2 ... user@host:
```

---

## Передача каталогов

Без специальных параметров `rsync` копирует файлы.

Для передачи всей иерархии каталога используется:

```
-a
```

Например:

```
rsync -a dir host:dest_dir
```

Параметр `-a` используется для копирования иерархии каталогов, включая:

- символические ссылки;
- права доступа;
- режимы;
- устройства.

---

## Пробный запуск

Если неясно, что именно будет передано, используется:

```
-n
```

Например:

```
rsync -nva dir host:dest_dir
```

Здесь:

```
-n → пробный запуск без копирования
-v → подробный вывод
-a → архивный режим для структуры каталога
```

Это особенно полезно перед потенциально опасными операциями.

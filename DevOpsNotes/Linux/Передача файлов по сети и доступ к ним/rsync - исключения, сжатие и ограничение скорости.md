## Исключение файлов

`rsync` позволяет исключать файлы и каталоги.

Например:

```
rsync -a --exclude=.git src host:
```

Исключаются все элементы, соответствующие шаблону:

```
.git
```

Для одного конкретного пути:

```
rsync -a --exclude=/src/.git src host:
```

Первая `/` в этом случае относится не к корню локальной системы, а к базовому каталогу передачи.

Можно использовать:

```
несколько --exclude
```

или файл шаблонов:

```
--exclude-from=file
```

## Сжатие

Для сжатия используется:

```
-z
```

Например:

```
rsync -az dir host:dest_dir
```

Сжатие может помочь при:

- медленном соединении;
- большой задержке;
- передаче большого объёма данных.

Однако в быстрой локальной сети сжатие может замедлить передачу из-за нагрузки на процессор.

---

## Ограничение пропускной способности

Для ограничения скорости используется:

```
--bwlimit
```

Пример:

```
rsync --bwlimit=100000 -a dir host:dest_dir
```

Это позволяет не полностью занимать восходящий канал и оставлять возможность другим TCP-соединениям использовать сеть.

## Передача с удалённого компьютера

`rsync` может копировать данные в обратном направлении:

```
rsync -a host:src_dir dest_dir
```

То есть:

```
удалённый источник
       ↓
локальный каталог назначения
```

`rsync` особенно полезен для:

- регулярного копирования;
- пакетной передачи;
- возобновления длительных передач;
- резервного копирования;
- синхронизации каталогов.

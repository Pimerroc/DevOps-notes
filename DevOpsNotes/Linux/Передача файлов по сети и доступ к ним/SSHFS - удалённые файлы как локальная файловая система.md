## Что такое SSHFS

**SSHFS** — файловая система пользовательского пространства.

Она:

1. открывает SSH-соединение;
2. получает доступ к файлам удалённой машины;
3. представляет их локально через точку монтирования.

Схема:

```
Локальный компьютер

mountpoint
     │
     ▼
SSHFS
     │
     │ SSH / SFTP
     ▼
Удалённый каталог
```

---

## Подключение

Базовый синтаксис:

```
sshfs username@host:dir mountpoint
```

Можно:

- не указывать `username@`, если имя пользователя совпадает;
- не указывать `:dir`, если требуется подключить домашний каталог.

При необходимости SSHFS запрашивает пароль удалённой стороны.

---

## Отключение

Для обычного пользователя:

```
fusermount -u mountpoint
```

Суперпользователь может использовать:

```
umount
```

Книга рекомендует обычно монтировать SSHFS от имени обычного пользователя для согласованности прав доступа и безопасности.

---

## Преимущества

### Минимальная настройка

Удалённому хосту необходимо поддерживать SFTP, что большинство SSH-серверов делают по умолчанию.

### Нет зависимости от конкретной сети

Если возможно установить SSH-соединение, SSHFS может работать независимо от того, находится ли удалённый хост:

- в локальной сети;
- в удалённой сети.

---

## Недостатки

- более низкая производительность;
- ресурсы тратятся на шифрование, трансляцию и передачу;
- ограниченные возможности многопользовательской настройки.

SSHFS подходит для небольших сценариев совместного доступа между Linux-машинами, когда важнее простота настройки, чем максимальная производительность.

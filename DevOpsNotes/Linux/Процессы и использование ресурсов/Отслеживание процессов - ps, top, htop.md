## Процессы и системные ресурсы

Процессы в Linux конкурируют за три основных вида аппаратных ресурсов:

- процессор;
- память;
- устройства ввода-вывода.

Задача ядра — распределять эти ресурсы между процессами.

Инструменты мониторинга производительности особенно полезны, когда система начинает работать медленно и необходимо определить причину.

При этом книга отдельно подчёркивает: не следует оптимизировать систему, которая уже работает нормально. Настройки по умолчанию в большинстве систем оптимальны, поэтому изменять их следует только при реальной необходимости.

## ps и top

Команда:

```bash
ps
````

показывает процессы и некоторую статистику их использования в определённый момент времени.

Однако `ps` плохо подходит для наблюдения за изменениями с течением времени.

Для интерактивного мониторинга используется:

```sh
top
```

`top`:

- отображает текущее состояние системы;
- показывает информацию о процессах;
- обновляет данные примерно каждую секунду;
- выводит наиболее активные процессы в верхней части списка.

По умолчанию наиболее активными считаются процессы, использующие больше всего процессорного времени.

---

## Основные клавиши top

### Пробел

Немедленно обновляет отображение.

### M

Сортирует процессы по текущему использованию памяти.

### T

Сортирует по общей (совокупной) загрузке процессора.

### P

Сортирует по текущей загрузке процессора.

Это сортировка по умолчанию.

### u

Показывает процессы только одного пользователя.

### f

Позволяет выбрать другую статистику для отображения.

### ?

Выводит краткую справку по основным командам `top`.

> Горячие клавиши `top` чувствительны к регистру.

## Аналогичные инструменты

Существуют утилиты:

```
atop
htop
btop
```

Они предоставляют дополнительные способы отображения и функции.

Например, `htop` использует многие возможности, связанные с информацией, которую можно получить через `lsof`.

## Практическая модель

Если система работает медленно, полезно начать с вопроса:

```
Что сейчас активно использует ресурсы?
```

Для этого:

```
ps
│
└── снимок процессов в конкретный момент

top
│
└── постоянное наблюдение за изменениями
```

`top` особенно полезен для поиска процессов, которые в данный момент активно используют:

```
CPU
```

или:

```
память
```

## MBR-загрузка

При традиционной загрузке BIOS после POST загружает и выполняет небольшой участок кода из MBR.

В MBR для этого доступно только **441 байт**, поэтому полноценный загрузчик туда не помещается.

Получается многоэтапная схема:

```text
BIOS
 ↓
MBR
 ↓
начальный фрагмент GRUB
 ↓
остальная часть GRUB
 ↓
ядро Linux
```
Остальные части загрузчика обычно помещаются в пространство между MBR и первым разделом.

Недостаток такого подхода: это пространство потенциально может быть перезаписано.

### MBR + GPT

Если используется GPT и загрузка через BIOS, обычная схема размещения GRUB после MBR не работает.

Причина в том, что после MBR располагается информация GPT.

Поэтому создают специальный:

```
BIOS Boot Partition
```

куда можно поместить необходимый код загрузчика.

## UEFI-загрузка

При UEFI прошивка умеет работать с файловыми системами и может найти файл загрузчика непосредственно в ESP.

Схема:

```
UEFI
 ↓
ESP
 ↓
*.efi
 ↓
GRUB
 ↓
Linux kernel
```

В этом случае ядро GRUB находится в ESP как файл.

Прошивка может перемещаться по ESP и непосредственно запускать GRUB или другой загрузчик.

## Secure Boot

UEFI может использовать механизм **Secure Boot**.

Когда Secure Boot активен, для запуска загрузчика требуется цифровая подпись поставщика.

Если загрузчик не подписан, прошивка отклоняет его и система не загружается.

Основные дистрибутивы Linux обычно решают проблему тем, что поставляют уже подписанные загрузчики, обычно основанные на версии GRUB для UEFI.

В некоторых случаях между UEFI и GRUB находится небольшой подписанный компонент:

```
UEFI
 ↓
подписанный компонент
 ↓
GRUB
```

Некоторые дистрибутивы требуют, чтобы подписанной была вся последовательность загрузки, включая ядро.

Secure Boot можно отключить в настройках UEFI, однако книга отмечает, что это может быть неприемлемо для систем с двойной загрузкой, например Windows.

## Chainloading

GRUB может запускать не только ядро Linux.

Он может передать управление другому загрузчику.

Это называется:

**chainloading — цепная загрузка.**

Например:

```
GRUB
 ↓
загрузчик Windows
 ↓
Windows
```

В конфигурации GRUB используется команда:

```
chainloader
```

Например:

```
menuentry "Windows" {
    insmod chain
    insmod ntfs
    set root=(hd0,3)
    chainloader +1
}
```

`+1` означает загрузку содержимого первого сектора раздела.

UEFI особенно удобно поддерживает несколько загрузчиков, поскольку в ESP можно размещать несколько загрузчиков.

```text
                    ДИСК
                      │
             ┌────────┴────────┐
             │                 │
            MBR               GPT
             │                 │
          обычно              обычно
           BIOS               UEFI
             │                 │
             ▼                 ▼
        код в MBR             ESP
             │                 │
             ▼                 ▼
           GRUB              *.efi
             │                 │
             └────────┬────────┘
                      ▼
                    GRUB
                      │
              grub.cfg + modules
                      │
              ┌───────┴────────┐
              ▼                ▼
          Linux kernel     другой загрузчик
              │             (chainloading)
              ▼
             initrd
              │
              ▼
       пользовательское
         пространство
```

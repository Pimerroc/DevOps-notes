## BIOS

При традиционной загрузке PC используется **BIOS (Basic Input-Output System)**.

После самотестирования оборудования (**POST**) BIOS ищет загрузочный код на устройствах хранения данных.

В классической схеме:

```text
BIOS
  ↓
MBR
  ↓
загрузчик
  ↓
ядро Linux
```
Проблема такого подхода заключается в том, что BIOS предоставляет загрузчику довольно ограниченный механизм доступа к диску.

Загрузчику всё равно необходимо найти ядро и прочитать его с диска, поэтому он должен уметь работать с таблицами разделов и файловыми системами.

## EFI

**EFI (Extensible Firmware Interface)** был разработан как замена традиционному BIOS.

EFI предоставляет прошивке больше возможностей для работы с устройствами хранения.

## UEFI

Современным стандартом является **UEFI (Unified EFI)**.

UEFI включает возможности:

- встроенной оболочки;
- чтения таблиц разделов;
- навигации по файловым системам;
- запуска загрузчиков.

**GPT является частью стандарта UEFI.**

Поэтому UEFI-загрузка принципиально отличается от MBR-загрузки.

### Главное различие

При MBR загрузчик начинает выполняться из небольшого участка загрузочного кода.

При UEFI прошивка может непосредственно найти файл загрузчика в специальном разделе и запустить его.

Упрощённо:
```
BIOS + MBR:

BIOS
 ↓
код в MBR
 ↓
части GRUB
 ↓
ядро GRUB
 ↓
Linux kernel
```

```
UEFI + ESP:

UEFI firmware
 ↓
ESP
 ↓
*.efi
 ↓
GRUB
 ↓
Linux kernel
```

### Как определить BIOS или UEFI в Linux

Книга предлагает:

```
efibootmgr
```

Если команда показывает цели загрузки — используется **UEFI**.

Если появляется сообщение, что переменные EFI не поддерживаются, используется **BIOS**.

Также можно проверить:

```
/sys/firmware/efi
```

Если этот каталог существует, система использует UEFI.

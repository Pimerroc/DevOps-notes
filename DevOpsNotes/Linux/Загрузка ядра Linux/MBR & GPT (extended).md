## Таблица разделов

Таблица разделов — это набор данных, который описывает, **как блоки диска разделены на разделы**.
Важно различать:
- **таблицу разделов** — определяет границы разделов на диске;
- **файловую систему** — организует файлы и каталоги внутри раздела.
Традиционная таблица разделов называется **MBR (Master Boot Record)**. Большинство новых систем используют **GPT (GUID/GUID Partition Table)**.

### MBR

MBR — традиционная схема, связанная с ранними PC и BIOS.

У MBR есть ограничение: базовая таблица позволяет иметь максимум **4 основных раздела**.

Если требуется больше:

1. один из разделов делают **расширенным (extended)**;
2. внутри расширенного раздела создают **логические разделы (logical)**.

Например:

```text
Disk
├── partition 1 — primary
└── partition 2 — extended
    └── partition 5 — logical
```
Поэтому нумерация разделов при MBR может выглядеть как:
```text
/dev/sda1
/dev/sda2
/dev/sda5
```
**parted** называет MBR-таблицу **msdos**.
### GPT

GPT — более новая схема таблицы разделов, которую используют большинство современных систем.

В отличие от MBR, GPT используется как часть стандартного способа загрузки через **UEFI**.

GRUB также различает таблицы разделов:
```text
(hd0,msdos1)   → MBR
(hd0,gpt1)     → GPT
```
То есть `msdos` в адресации GRUB указывает на MBR, а `gpt` — на GPT.

### Связь MBR/GPT с загрузкой

Важно не смешивать:
```text
MBR / GPT
    ↓
таблица разделов
```
и
```text
BIOS / UEFI
    ↓
способ загрузки
```
На практике классическая схема выглядит как:
BIOS + MBR
а современная:

```
UEFI + GPT
```

Однако книга отдельно рассматривает необычный вариант:

```
BIOS + GPT
```

Для него требуется специальный небольшой **BIOS Boot Partition**, поскольку обычное размещение частей загрузчика после MBR в случае GPT невозможно.

В книге отмечается, что такая конфигурация встречается редко; обычно GPT используется вместе с UEFI.

# Квиз по главе 6

Автономная браузерная страница с 15 вопросами по транспортному уровню.
Ответы и разбор показываются только после завершения. После каждого ответа
нужно отметить уверенность: 1 — не уверен, 2 — сомневаюсь, 3 — уверен.

## Быстрый запуск

Открой `quiz.html` двойным щелчком. В конце нажми **«Скачать JSON»** или
**«Скопировать JSON»** и передай файл/текст агенту.

## Запуск с автосохранением

```bash
python3 server.py
```

Сервер откроет `http://127.0.0.1:8765/` и после прохождения запишет результат в:

- `results/latest.json` — последняя попытка;
- `results/quiz-ch6-YYYYMMDD-HHMMSS.json` — история попыток.

Остановить — `Ctrl+C`. Другой порт:

```bash
python3 server.py --port 8766
```

Если страница открыта как файл, а сервер запущен на нестандартном порту,
автосохранение не сработает: используй кнопку скачивания или открой страницу
через адрес сервера.

## Что в JSON

| Поле | Что означает |
| --- | --- |
| `score`, `total`, `percent` | итог |
| `blocks` | результат по блокам A и B |
| `calibration` | сколько ответов каждой уверенности и сколько из них верны |
| `mistakes` | номера неверных вопросов |
| `dangerousMistakes` | ошибки с уверенностью 3 — главные пробелы |
| `luckyGuesses` | верные ответы с уверенностью 1 — возможные случайности |
| `answers` | полный разбор: вопрос, твой ответ, правильный ответ, уверенность, время, объяснение |

`results/` исключён из git: это личные попытки, а не часть заметок.

# Словарь сокращений — вся книга

> Источник: Таненбаум, Фимстер, Уэзеролл. *Компьютерные сети*, 6-е изд. — главы 1–8 (стр. 26–983).
> Книга ведёт собственный «Список аббревиатур» на стр. 22 (105 сокращений) и обещает, что «каждая аббревиатура выделена жирным шрифтом и расшифрована» по ходу текста.
>
> **Эта заметка — то, чего в книге не хватает.** В графе «в книге» отмечено, где книга расшифровывает сокращение, а где **нет** и от читателя требуется знать его заранее.
> В главах 1–4 подобных «немых» сокращений, встречающихся в проверяемых утверждениях, набралось **7** — они и есть главный источник недопонимания при чтении. Список — в конце заметки. Главы 7–8 (прикладной уровень и безопасность) добавили свой слой терминов — разделы ниже.

> В книге три разных написания высоты для MEO/LEO — в одном месте 10 000, в другом 500–1500, потому что границы поясов радиации «размыты». Ключевое для запоминания — **задержка**:

| Пара | Разница |
| --- | --- |

### Пары главы 6, которые путают

| Пара | Разница |
| --- | --- |
| **SYN** ↔ **FIN** | открывает соединение ↔ закрывает одно направление |
| **ACK на SYN** ↔ **ACK на данные** | подтверждает номер 1001 после SYN ↔ подтверждает следующий байт данных |
| **TIME WAIT** ↔ **CLOSE WAIT** | ждём исчезновения старых пакетов (2T) ↔ ждём закрытия приложения |
| **4 сегмента** ↔ **3 сегмента** | FIN и ACK в каждом направлении ↔ ACK на FIN совмещён со встречным FIN |
| **cwnd** ↔ **окно получателя** | ограничение сети ↔ свободное место в буфере получателя |
| **ssthresh** ↔ **cwnd** | порог переключения на линейный рост ↔ текущее окно |
| **RTO** ↔ **RTT** | тайм-аут с запасом ↔ измеренное время круга |
| **SRTT** ↔ **RTTVAR** | среднее RTT ↔ разброс RTT; RTO = SRTT + 4·RTTVAR |
| **AIMD** ↔ **slow start** | +1 сегмент за RTT после порога ↔ удвоение каждый RTT до порога |
| **Tahoe** ↔ **Reno** | при потере cwnd = 1 ↔ быстрое восстановление, cwnd ≈ ssthresh |
| **CUBIC** ↔ **BBR** | окно как кубическая функция времени ↔ оценка BDP и пейсинг без ожидания потерь |
| **UDP** ↔ **TCP** | без соединения и гарантий ↔ соединение, порядок, надёжность, контроль перегрузки |
| **RTP** ↔ **RTCP** | данные реального времени ↔ обратная связь о качестве |
| **TPDU** ↔ **сегмент** | старое название ↔ современный термин TCP/UDP |
| **TSAP** ↔ **NSAP** | транспортный адрес (порт) ↔ сетевой адрес (IP) |
| **BDP** ↔ **BD** | одно и то же произведение полосы на задержку; BD — термин главы 3 |

> [!note]- ECN, RED, FEC и QoE
> Эти механизмы уже разобраны в главах 3–5. В главе 6 они используются как готовые: ECN — пометка вместо сброса при перегрузке, RED — раннее обнаружение, FEC — восстановление без повтора, QoE — качество пользовательского опыта.

## Как этим пользоваться

1. Читай главы по конспектам ([[Глава 1]]–[[Глава 8]]), выписывая незнакомые сокращения в эту таблицу.
2. Ошибки почти всегда одного из двух видов: **забыл расшифровку** либо **спутал две похожие аббревиатуры**. Второе важнее — см. таблицы пар выше.
3. Всё, что книга не расшифровывает, собрано в таблицу «Немые сокращения» — эти определения стоит выучить наизусть: проверка чаще всего строится именно на них.

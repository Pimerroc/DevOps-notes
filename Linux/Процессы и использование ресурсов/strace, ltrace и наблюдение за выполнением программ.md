## Зачем нужны эти инструменты

Инструменты вроде `ps` и `lsof` хорошо работают с уже запущенными процессами.

Но возникает другая ситуация:

```text
программа запускается
      ↓
немедленно завершается
````

В таком случае может быть трудно понять, что именно она пыталась сделать.

Для этого используются:

```
strace
ltrace
```

---

# strace

`strace` означает:

```
system call trace
```

То есть отслеживание системных вызовов.

Системный вызов — это привилегированная операция, которую процесс пользовательского пространства запрашивает у ядра.

Примеры:

- открыть файл;
- прочитать данные;
- создать процесс;
- выделить память.

`strace` показывает системные вызовы, выполняемые программой.

---

## Пример

В книге используется:

```
strace cat /dev/null
```

В начале вывода можно увидеть:

```
execve("/bin/cat", ["cat", "/dev/null"], ...) = 0
brk(NULL) = ...
```

### execve()

Запускает новую программу.

### brk()

Связан с инициализацией памяти процесса.

---

## Открытие файла

Позже программа выполняет:

```
openat(..., "/dev/null", O_RDONLY) = 3
```

Значение:

```
3
```

— файловый дескриптор, возвращённый ядром после успешного открытия файла.

Затем программа выполняет:

```
read(3, ...)
```

После окончания чтения:

```
close(3)
```

и завершает работу:

```
exit_group(0)
```

Таким образом, `strace` позволяет наблюдать реальное взаимодействие программы с ядром.

---

## Поиск ошибки

Книга приводит пример:

```
strace cat not_a_file
```

Можно увидеть:

```
openat(..., "not_a_file", O_RDONLY) =
-1 ENOENT (No such file or directory)
```

Здесь:

```
-1
```

означает ошибку.

```
ENOENT
```

указывает тип ошибки:

```
No such file or directory
```

`strace` особенно полезен для поиска отсутствующих файлов и других ошибок, которые сложно обнаружить через обычные журналы.

---

## Сохранение вывода

По умолчанию `strace` выводит информацию в:

```
stderr
```

Для сохранения используется:

```
strace -o save_file command
```

Можно также перенаправить стандартную ошибку:

```
command 2> save_file
```

---

# ltrace

`ltrace` означает:

```
library trace
```

Он используется для наблюдения за вызовами библиотек.

Упрощённо:

```
strace
   ↓
системные вызовы
   ↓
ядро

ltrace
   ↓
вызовы библиотек
   ↓
библиотеки программы
```

Оба инструмента могут создавать очень большой объём вывода.

Поэтому при работе с ними важно заранее понимать, какую проблему необходимо искать.

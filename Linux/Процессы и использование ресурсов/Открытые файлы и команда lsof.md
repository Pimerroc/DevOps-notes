## Идея lsof

Команда:

```bash
lsof
````

означает:

```
list open files
```

Она выводит список открытых файлов и процессов, которые их используют.

В Unix понятие файла используется очень широко, поэтому `lsof` не ограничивается обычными файлами.

Она может показывать:

- обычные файлы;
- каталоги;
- сетевые ресурсы;
- динамические библиотеки;
- конвейеры;
- другие открытые объекты.

Поэтому `lsof` является важным инструментом поиска проблем.

---

## Пример вывода

В книге приведён пример:

```
COMMAND  PID   USER   FD   TYPE ...
systemd  1     root   cwd  DIR  ...
systemd  1     root   txt  REG  ...
vi       1994  juser  cwd  DIR  ...
vi       1994  juser  3u   REG  ...
```

Основные поля:

### COMMAND

Имя команды процесса, которому принадлежит открытый объект.

### PID

Идентификатор процесса.

### USER

Пользователь, выполняющий процесс.

### FD

Может показывать:

- назначение файла;
- файловый дескриптор.

Файловый дескриптор — это число, которое процесс использует вместе с системными библиотеками и ядром для идентификации и управления открытым файлом.

Например:

```
3
```

— файловый дескриптор.

---

### TYPE

Тип объекта.

Например:

```
REG
```

обычный файл.

```
DIR
```

каталог.

Также могут встречаться сокеты и другие типы объектов.

---

### DEVICE

Основной и второстепенный номера устройства, на котором расположен файл.

### SIZE/OFF

Размер файла.

### NODE

Номер inode.

### NAME

Имя файла.

---

## cwd

В поле `FD` может встречаться:

```
cwd
```

Это означает текущий рабочий каталог процесса.

Например:

```
vi 1994 juser cwd DIR ... /home/juser
```

показывает текущий рабочий каталог процесса `vi`.

---

## Основные способы использования

### Просмотреть всё

```
lsof
```

Затем большой вывод можно передать программе просмотра.

---

### Ограничить поиск каталогом

Например:

```
lsof +D /usr
```

Показывает записи для файлов, открытых в:

```
/usr
```

и его подкаталогах.

---

### Найти открытые файлы процесса

```
lsof -p pid
```

где `pid` — идентификатор процесса.

---

## Важное свойство lsof

`lsof` сильно зависит от информации ядра.

После обновления дистрибутива, при котором обновились одновременно ядро и `lsof`, новая версия `lsof` может работать неправильно до перезагрузки ядра.

## Системное время

Система использует собственное представление времени.

При работе со временем важны:

```text
время ядра
часовой пояс
сетевое время
````

Сетевое время используется для синхронизации системных часов.

---

# cron

`cron` используется для выполнения повторяющихся задач.

Задача описывается в:

```
crontab
```

Для установки файла:

```
crontab file
```

Просмотр задач:

```
crontab -l
```

Удаление:

```
crontab -r
```

Редактирование:

```
crontab -e
```

---

## Системный crontab

Для системных задач используется:

```
/etc/crontab
```

В системном crontab присутствует дополнительное поле:

```
время + пользователь + команда
```

Например:

```
42 6 * * * root /usr/local/bin/cleansystem
```

Здесь задача выполняется:

```
в 06:42
```

от имени:

```
root
```

Некоторые дистрибутивы используют также:

```
/etc/cron.d/
```

---

# systemd timers

В systemd существуют:

```
timer units
```

Они могут использоваться для планирования задач.

Таким образом, в современной системе повторяющиеся задачи могут запускаться через:

```
cron
```

или:

```
systemd timer units
```

---

# at

`at` используется для планирования:

```
разовой задачи
```

То есть:

```
cron
    ↓
повторяющиеся задачи

at
    ↓
однократная задача
```

# PAM

PAM:

```
Pluggable Authentication Modules
```

представляет систему подключаемых модулей аутентификации.

Приложение передаёт выполнение аутентификации PAM.

Это позволяет использовать различные методы проверки пользователя.

Например:

- пароли;
- дополнительные механизмы;
- двухфакторные методы;
- физические ключи.

Конфигурация PAM обычно находится в:

```
/etc/pam.d/
```

---

## Строка конфигурации PAM

Пример:

```
auth requisite pam_shells.so
```

Строка состоит из:

```
function type
control argument
module
```

---

## Типы функций PAM

### auth

Аутентификация пользователя.

```
Является ли пользователь тем,
кем себя называет?
```

### account

Проверка состояния учётной записи.

### session

Действия, относящиеся к пользовательскому сеансу.

### password

Изменение пароля или других учётных данных.

---

## Основная идея PAM

PAM отделяет:

```
программу
```

от конкретного:

```
механизма аутентификации
```

Схема:

```
application
      ↓
PAM
      ↓
authentication modules
      ↓
authentication method
```

Это позволяет изменять способы аутентификации без необходимости переписывать каждую программу.

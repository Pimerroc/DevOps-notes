## Пользователь в Unix

Unix и Linux поддерживают несколько независимых пользователей.

На уровне ядра пользователь представлен числом:

```text
UID
````

User ID — идентификатор пользователя.

Имя пользователя:

```
username
```

существует для удобства работы человека.

Программа при необходимости должна сопоставить:

```
username
    ↕
UID
```

Ядро использует числовые идентификаторы.

---

## /etc/passwd

Файл:

```
/etc/passwd
```

сопоставляет:

```
имя пользователя
        ↓
UID
```

Каждая строка представляет одного пользователя.

Формат содержит семь полей:

```
username:password:UID:GID:GECOS:home:shell
```

### Поля

1. Имя пользователя.
2. Поле пароля.
3. UID — идентификатор пользователя.
4. GID — идентификатор основной группы.
5. GECOS — информация о пользователе.
6. Домашний каталог.
7. Оболочка пользователя.

Пример структуры:

```
user:x:1000:1000:Name:/home/user:/bin/bash
```

---

## Поле пароля

В большинстве современных систем пароль фактически хранится не в:

```
/etc/passwd
```

а в:

```
/etc/shadow
```

Символ:

```
x
```

в `/etc/passwd` означает, что пароль хранится в shadow.

Пароли не хранятся в открытом виде.

Поле содержит производную от пароля.

Если используется:

```
*
```

пользователь не может войти в систему.

Пустое поле пароля означает возможность входа без пароля.

Книга отдельно предупреждает не оставлять такие поля пустыми.

---

## /etc/shadow

Файл:

```
/etc/shadow
```

используется для хранения информации о паролях.

В отличие от `/etc/passwd`, обычные пользователи не имеют разрешения на его чтение.

Это отделяет информацию, необходимую для идентификации пользователя, от информации, необходимой для проверки пароля.

---

## Управление пользователями

Хотя `/etc/passwd` является текстовым файлом, прямое редактирование нежелательно.

Причины:

- легко допустить ошибку;
- возможны проблемы при одновременном изменении данных несколькими источниками.

Для управления используются специальные команды.

Например:

```
passwd
```

изменяет пароль.

```
adduser
```

добавляет пользователя.

```
userdel
```

удаляет пользователя.

Для безопасного редактирования файла используются:

```
vipw
```

Для `/etc/shadow`:

```
vipw -s
```

Эти программы обеспечивают дополнительные меры безопасности при редактировании.

## Назначение журналов

Системный журнал хранит информацию о событиях, происходящих в системе.

Журналы используются для:

- диагностики ошибок;
- отслеживания работы служб;
- анализа процесса загрузки;
- поиска системных событий.

Современная система может использовать несколько механизмов журналирования.

В systemd важную роль играет:

```text
journald
````

Это служба ведения системного журнала.

Она является одним из компонентов современной системы systemd.

---

## Работа с журналами

При работе с журналами важны следующие задачи:

```
поиск
мониторинг
обслуживание
ротация
```

### Поиск

Журналы позволяют находить сообщения, связанные с определённым:

- событием;
- временем;
- службой;
- компонентом системы.

### Мониторинг

Можно отслеживать появление новых сообщений во время работы системы.

Это особенно полезно при:

```
отладке службы
```

или наблюдении за процессом запуска.

---

## Ротация журналов

Файлы журналов могут постоянно увеличиваться.

Поэтому требуется:

```
log rotation
```

Ротация означает управление старыми журналами:

```
старый журнал
      ↓
архивирование / переименование
      ↓
создание нового журнала
      ↓
удаление слишком старых данных
```

Это предотвращает бесконечный рост файлов журналов.

---

## journald и традиционный журнал

`journald` обрабатывает несколько механизмов журналирования, включая взаимодействие с традиционной службой системного журнала Unix:

```
syslog
```

Таким образом, журналирование в современной Linux-системе может включать несколько уровней:

```
программа
    ↓
служба
    ↓
journald / syslog
    ↓
журнальные данные
```

## Основная идея

Журналы — это историческая информация о состоянии системы.

При возникновении проблемы полезная последовательность анализа выглядит так:

```
проблема
   ↓
сообщения службы
   ↓
системный журнал
   ↓
поиск события
   ↓
анализ причины
```

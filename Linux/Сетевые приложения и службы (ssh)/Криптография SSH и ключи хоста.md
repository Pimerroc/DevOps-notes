## Открытый и закрытый ключ

SSH использует криптографию с открытым ключом.

Каждая пара состоит из:

```
Открытый ключ
     +
Закрытый ключ
```

Основной принцип:

```
данные, зашифрованные открытым ключом
        ↓
могут быть расшифрованы соответствующим
закрытым ключом
```

Закрытый ключ необходимо защищать.

Книга отдельно предупреждает, что нельзя позволять другим лицам получать доступ к закрытому ключу, поскольку его компрометация может позволить злоумышленнику проникнуть в систему.

Ключи также используются не только для шифрования, но и для **аутентификации**: можно проверить, что сторона владеет соответствующим закрытым ключом, не передавая сам ключ.

## Ключи SSH-сервера

SSH-сервер использует ключи хоста.

В OpenSSH каждый набор состоит из:

```
Закрытый ключ
Открытый ключ (.pub)
```

В книге приводятся, например:

```
ssh_host_rsa_key
ssh_host_rsa_key.pub

ssh_host_dsa_key
ssh_host_dsa_key.pub
```

Соответственно:

- файл без `.pub` — закрытый ключ;
- файл с `.pub` — открытый ключ.

Создание ключей выполняется с помощью:

```
ssh-keygen
```

Примеры из книги:

```
ssh-keygen -t rsa -N '' -f /etc/ssh/ssh_host_rsa_key
```

```
ssh-keygen -t dsa -N '' -f /etc/ssh/ssh_host_dsa_key
```

Однако обычно вручную создавать ключи хоста не требуется: установщик OpenSSH или сценарии дистрибутива делают это автоматически.

## `ssh_known_hosts`

SSH-серверы и клиенты используют файл:

```
ssh_known_hosts
```

для хранения открытых ключей известных хостов.

Знание о таких файлах особенно полезно при замене компьютера или восстановлении системы: можно перенести соответствующие ключи со старой машины, чтобы пользователи не сталкивались с несоответствием ключей после замены хоста.

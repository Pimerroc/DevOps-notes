## Что такое SSH

**SSH (Secure Shell)** — один из наиболее распространённых способов удалённого доступа к Unix-системам.

SSH предназначен для:

- безопасного входа в оболочку удалённой машины;
- удалённого запуска программ;
- передачи файлов;
- туннелирования других сетевых соединений.

SSH заменяет более старые небезопасные системы удалённого доступа:

```
telnet
rlogin
```

Основная причина использования SSH — защита соединения.

SSH:

- шифрует пароль;
- шифрует остальные данные сеанса;
- использует криптографию с открытым ключом для аутентификации;
- позволяет идентифицировать удалённый хост.

Популярной реализацией SSH для Unix является:

```
OpenSSH
```

В OpenSSH:

```
ssh   → клиент
sshd  → сервер
```

OpenSSH поддерживает SSH версии 2 и не поддерживает SSH версии 1 из-за уязвимостей и её устаревания.

## Общая схема SSH

```
Локальный компьютер
────────────────────

ssh
 │
 │ зашифрованное соединение
 ▼
─────────────────────────────
            Сеть
─────────────────────────────
 │
 ▼
sshd
Удалённый компьютер
```

SSH может использоваться не только для получения интерактивной оболочки. Через него можно выполнять отдельные команды и передавать файлы.

Например, можно запускать конвейер, передавая данные через SSH:

```
tar zcvf - dir | ssh remote_host tar zxvf -
```

Здесь:

1. локальная `tar` создаёт архив;
2. архив передаётся через SSH;
3. на удалённой машине вторая `tar` распаковывает его.

Это показывает, что SSH можно использовать как защищённый канал для передачи потоков данных между машинами.

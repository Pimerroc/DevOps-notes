OpenSSH включает программы передачи файлов:

```
scp
sftp
```

Они предназначены для замены старых небезопасных программ:

```
rcp
ftp
```

---

## `scp`

`scp` работает аналогично `cp`.

### Копирование с удалённого хоста

```
scp user@host:file .
```

Копирует файл с удалённого хоста в текущий каталог.

---

### Копирование на удалённый хост

```
scp file user@host:dir
```

Копирует локальный файл в каталог на удалённой машине.

---

### Копирование между двумя удалёнными хостами

```
scp user1@host1:file user2@host2:dir
```

---

## `sftp`

`sftp` похож на старый интерактивный FTP-клиент командной строки.

Используются команды:

```
get
put
```

На удалённом хосте должен быть доступен сервер SFTP. Обычно его можно ожидать на машине, использующей OpenSSH.

Если требуется передавать большое количество файлов и нужна большая гибкость, книга рекомендует рассмотреть:

```
rsync
```

который подробно разбирается в главе 12.

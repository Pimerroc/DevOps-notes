## Базовое подключение

SSH-клиент подключается к удалённому хосту и устанавливает защищённый сеанс.

Конфигурация глобального SSH-клиента находится в:

```
/etc/ssh/ssh_config
```

Как и `sshd_config`, этот файл содержит пары:

```
ключ → значение
```

Обычно его не требуется изменять.

## `known_hosts`

Одна из наиболее распространённых проблем SSH возникает, когда сохранённый открытый ключ удалённого хоста не совпадает с ключом, который хост предоставляет сейчас.

Ключи могут храниться, например, в:

```
~/.ssh/known_hosts
```

или в глобальном файле:

```
ssh_known_hosts
```

При несовпадении появляется предупреждение вида:

```
WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!
```

SSH предупреждает, что возможны два принципиально разных случая:

1. ключ хоста действительно был изменён;
2. происходит атака «человек посередине» (`man-in-the-middle`).

Поэтому изменение ключа не следует автоматически игнорировать.

Если изменение действительно подтверждено, неправильный ключ необходимо удалить или заменить правильным.

В сообщении SSH может указываться конкретная строка файла:

```
Offending key in /home/user/.ssh/known_hosts:12
```

Это означает, что неправильная запись находится в строке `12`.

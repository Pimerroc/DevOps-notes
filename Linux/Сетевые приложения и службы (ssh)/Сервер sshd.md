## Конфигурация SSH-сервера

Для работы `sshd` необходимы:

```
Конфигурация
+
Ключи хоста
```

Конфигурационные файлы обычно находятся в:

```
/etc/ssh
```

Основной файл конфигурации сервера:

```
/etc/ssh/sshd_config
```

Важно не путать его с конфигурацией клиента:

```
/etc/ssh/ssh_config
```

Файл `sshd_config` состоит из пар:

```
ключ → значение
```

Например:

```
Port 22
```

Многие параметры в файле могут быть закомментированы:

```
#AddressFamily any
#ListenAddress 0.0.0.0
#ListenAddress ::
```

Комментарии часто показывают значения по умолчанию.

---

## Важные параметры `sshd_config`

### `HostKey file`

Определяет файл ключа хоста.

---

### `PermitRootLogin value`

Определяет возможность входа суперпользователя через SSH.

Например:

```
PermitRootLogin no
```

предотвращает вход `root` по SSH.

---

### `LogLevel level`

Определяет уровень сообщений, записываемых в системный журнал.

По умолчанию используется:

```
INFO
```

---

### `SyslogFacility name`

Определяет объект системного журнала.

Для SSH по умолчанию используется:

```
AUTH
```

---

### `X11Forwarding value`

Включает туннелирование клиентов X Window System.

---

## Запуск `sshd`

Поведение зависит от дистрибутива.

Например, в некоторых системах сервер может быть установлен, но отключён.

Для запуска при загрузке:

```
systemctl enable sshd
```

Для немедленного запуска:

```
systemctl start sshd
```

В некоторых дистрибутивах установка пакета SSH:

1. создаёт необходимые ключи;
2. запускает сервер;
3. добавляет его в конфигурацию загрузки.

Существуют два основных режима запуска серверов:

```
автономный
по требованию
```

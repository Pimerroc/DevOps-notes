## Samba — кратко

**Samba** используется для совместного доступа между Linux и Windows через стандартный протокол Windows:

```
SMB
Server Message Block
```

Samba позволяет:

```
Windows → получать доступ к Linux-файлам
Linux   → получать доступ к Windows-файлам
```

Также Samba может использоваться для работы с принтерами.

Для базовой настройки Samba необходимо:

1. создать `smb.conf`;
2. добавить разделы совместного доступа к файлам;
3. при необходимости добавить принтеры;
4. запустить соответствующие службы Samba.

Книга специально не рассматривает сложную настройку Samba подробно, поскольку существует большое количество вариантов конфигурации и управления доступом.

## CIFS

Для подключения ресурса Windows в Linux используется CIFS.

Пример:

```
mount -t cifs SERVER:sharename mountpoint -o user=username,pass=password
```

## Общий принцип безопасности

При совместном доступе к файлам необходимо учитывать два независимых аспекта:

```
Аутентификация / авторизация
+
Шифрование
```

Аутентификация и авторизация должны гарантировать:

```
доступ имеют только стороны
с правильными учётными данными
```

Шифрование должно гарантировать:

```
данные нельзя прочитать
при перехвате во время передачи
```

Книга подчёркивает, что самые простые в настройке системы совместного доступа часто оказываются наименее безопасными.

Если есть сомнения в безопасности сети между компьютерами, использующими общий доступ, следует применять:

- аутентификацию;
- авторизацию;
- шифрование.

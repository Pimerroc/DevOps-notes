	Таблица разделов — структура на диске, описывающая, где находятся разделы, какого они размера и типа. Она нужна прошивке/ОС для интерпретации разметки диска.

### MBR — Master Boot Record

	Старая схема разметки диска, в которой информация о разделах хранится в начале диска в partition table внутри первого сектора.

- Максимум 4 primary-раздела.
- Для создания большего числа разделов используется extended partition + logical partitions.
- Классический MBR ограничивает адресацию дисков примерно 2 TiB при размере сектора 512 байт..
- Также содержит небольшой bootloader code..
- Используется преимущественно вместе с Legacy BIOS..

### GPT — GUID Partition Tabl.

	Современная схема разметки диска, являющаяся частью стандарта UEFI.

- Поддерживает большое количество разделов (обычно 128 в типичной реализации).
- Не имеет классического ограничения MBR в 2 TiB.
- Каждый раздел имеет уникальный GUID.
- Имеет резервную копию таблицы в конце диска.
- Содержит CRC32, позволяющие обнаруживать повреждение структуры.
- Обычно используется вместе с UEFI.

# ESP — EFI System Partition

При UEFI-загрузке используется специальный системный раздел:

**ESP (EFI System Partition)**.

Это специальная файловая система **VFAT**, содержащая каталог:

```text
EFI/
```
В Linux ESP обычно монтируется в:

```
/boot/efi
```

Поэтому структура загрузчиков обычно находится внутри:

```
/boot/efi/EFI/
```

Каждый загрузчик имеет собственный идентификатор и подкаталог.

Например:

```
EFI/
├── microsoft/
├── apple/
├── ubuntu/
└── grub/
```

Файлы загрузчиков имеют расширение:

```
.efi
```

Например, книга приводит:

```
grubx64.efi
shimx64.efi
```

где `grubx64.efi` — версия GRUB для EFI.

### ESP ≠ BIOS Boot Partition

Это принципиально разные вещи.

**BIOS Boot Partition** используется в специальной конфигурации для загрузки BIOS с GPT.

**ESP** используется для UEFI.

У них разные UUID.

### Почему нельзя использовать старый GRUB BIOS в ESP

Код загрузчика, написанный для BIOS, нельзя просто скопировать в ESP.

Для UEFI требуется загрузчик, предназначенный именно для UEFI.

Например, для GRUB необходимо установить:

```
GRUB для UEFI
```

а не:

```
GRUB для BIOS
```

Кроме копирования загрузчика в ESP, необходимо сообщить прошивке о новом загрузчике.

Для этого используется **NVRAM**.

Книга показывает установку GRUB через:

```
grub-install --efi-directory=efi_dir --bootloader-id=name
```

`efi_dir` — расположение ESP в системе.

Обычно ESP монтируется в:

```
/boot/efi
```

При установке GRUB также используется `efibootmgr` для сохранения конфигурации загрузчика в NVRAM.

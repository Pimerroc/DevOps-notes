# GRUB

**GRUB (Grand Unified Boot Loader)** — загрузчик Linux.

В книге рассматривается **GRUB 2**. Более старая версия называется GRUB Legacy.

Основная идея GRUB — дать возможность выбрать:

- ядро Linux;
- параметры ядра;
- другую операционную систему.

GRUB умеет работать с файловыми системами, поэтому может самостоятельно искать необходимые файлы.

## GRUB и его собственное «ядро»

Важно не путать:

```text
Linux kernel
```
и
```
GRUB kernel
```

GRUB имеет собственное ядро и собственные команды.

Например:

```
insmod
ls
```

— это команды GRUB, а не Linux.

Поэтому `root` в конфигурации GRUB также может иметь два разных смысла.

### root GRUB

Например:

```
set root=(hd0,msdos1)
```

означает файловую систему, в которой GRUB ищет свои файлы.

### root Linux

В строке:

```
linux /boot/vmlinuz... root=UUID=...
```

`root=` уже является параметром, который передается **ядру Linux**.

## Конфигурация GRUB

Обычно конфигурация находится в:

```
/boot/grub
```

или:

```
/boot/grub2
```

Главный файл:

```
grub.cfg
```

В нём находятся команды GRUB и пункты меню:

```
menuentry
```

Примерная структура загрузки:
```
set root=...
search ...
linux /boot/vmlinuz-...
initrd /boot/initrd.img-...
```

`linux` указывает на образ ядра.

`initrd` указывает на начальную файловую систему оперативной памяти.

### Не редактировать grub.cfg напрямую

Книга специально предупреждает: `grub.cfg` не следует редактировать вручную.

Он создаётся автоматически.

Для генерации используется:

```
grub-mkconfig
```

Например:

```
grub-mkconfig -o /boot/grub/grub.cfg
```

Скрипты, из которых создаётся конфигурация, находятся в:

```
/etc/grub.d/
```

`grub-mkconfig` запускает эти скрипты и собирает из их результатов `grub.cfg`.

Важно:

```
/etc/grub.d/*
       ↓
grub-mkconfig
       ↓
/boot/grub/grub.cfg
       ↓
GRUB при загрузке
```

Сами скрипты `/etc/grub.d/` GRUB во время загрузки не запускает.

## Адресация устройств в GRUB

GRUB использует собственную схему имён.

Например:

```
(hd0)
(hd1)
```

Первый найденный жёсткий диск — `hd0`, следующий — `hd1`.

Разделы:

```
(hd0,msdos1)
(hd0,msdos2)
```

для MBR.

Для GPT:

```
(hd0,gpt1)
(hd0,gpt2)
```

GRUB также умеет искать раздел по UUID:

```
search ...
```

Это позволяет не зависеть от конкретного сопоставления устройств.

## Как GRUB загружает Linux

Общий процесс:

1. BIOS или UEFI инициализирует оборудование.
2. Прошивка находит загрузочный код.
3. Запускается GRUB.
4. Загружается и инициализируется ядро GRUB.
5. GRUB получает доступ к дискам и файловым системам.
6. GRUB находит свой загрузочный раздел.
7. Загружает конфигурацию.
8. Пользователь может изменить параметры загрузки.
9. GRUB выполняет конфигурацию из `grub.cfg`.
10. При необходимости загружает дополнительные модули.
11. Команда `boot` запускает ядро Linux.

То есть:

```
Firmware
   ↓
GRUB
   ↓
grub.cfg
   ↓
linux /boot/vmlinuz...
   +
initrd /boot/initrd...
   ↓
Linux kernel
```

Где именно находится GRUB, зависит от схемы загрузки.

Возможные варианты:

- частично между MBR и первым разделом;
- в обычном разделе;
- в специальном загрузочном разделе;
- в ESP при использовании UEFI.

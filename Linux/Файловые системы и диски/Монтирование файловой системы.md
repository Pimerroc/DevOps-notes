**Монтирование** — присоединение файловой системы к текущему дереву каталогов Linux.

Чтобы смонтировать ФС, необходимо знать:

1. **Источник** — устройство, раздел или идентификатор ФС.
2. **Тип файловой системы** — например, `ext4`, `vfat`, `iso9660`.
3. **Точку монтирования** — существующий каталог, через который будет доступна ФС.

Например:

```bash
mount -t ext4 /dev/sdf2 /home/extra
```

После этого содержимое `/dev/sdf2` становится доступно через:

```text
/home/extra/
```

Точка монтирования может находиться в любом месте дерева каталогов.

### Просмотр смонтированных ФС

```bash
mount
```

Типичная строка:

```text
/dev/sda1 on / type ext4 (rw,errors=remount-ro)
```

Её структура:

```text
устройство on точка_монтирования type тип_ФС (параметры)
```

### Размонтирование

```bash
umount /home/extra
```

Можно также указать устройство вместо точки монтирования:

```bash
umount /dev/sdf2
```

Для экспериментов обычно используют `/mnt` как временную точку монтирования.

## `/etc/fstab` — постоянная конфигурация монтирования

`/etc/fstab` содержит постоянный список файловых систем и их параметров. Он позволяет автоматически монтировать ФС при загрузке и использовать короткие команды `mount`.

Пример:

```text
UUID=70ccd6e7-6ae6-44f6-812c-51aab8036d29 / ext4 errors=remount-ro 0 1
UUID=592dcfd1-58da-4769-9ea8-5f412a896980 none swap sw 0 0
/dev/sr0 /cdrom iso9660 ro,user,nosuid,noauto 0 0
```

Каждая строка содержит **6 полей**:

```text
1. источник / UUID
2. точка монтирования
3. тип ФС
4. параметры
5. параметры dump
6. порядок проверки fsck
```

Например:

```text
UUID=... / ext4 errors=remount-ro 0 1
```

означает:

```text
UUID=...          → какую ФС использовать
/                 → куда монтировать
ext4              → тип
errors=remount-ro → параметры
0                 → dump не используется
1                 → проверять первой
```

### Полезные параметры

`defaults` — стандартный набор параметров монтирования.

`noauto` — не монтировать автоматически через `mount -a`.

`user` — разрешает непривилегированному пользователю выполнять монтирование соответствующей записи.

`errors=remount-ro` — для ext2/ext3/ext4 при ошибке повторно монтировать ФС в режиме read-only.

### Полезные команды

```bash
mount -a
```

Монтирует записи из `/etc/fstab`, кроме записей с `noauto`.

Файл `/etc/fstab` остаётся традиционным способом настройки. Также существуют `/etc/fstab.d` и systemd units, причём systemd-конфигурация часто генерируется на основе `/etc/fstab`.

Имена устройств вроде:

```text
/dev/sda1
/dev/sdb1
```

могут изменяться в зависимости от порядка обнаружения устройств ядром.

Поэтому файловые системы можно идентифицировать по **UUID** — уникальному идентификатору, который создаётся при инициализации файловой системы.

Посмотреть UUID:

```bash
blkid
```

Например:

```text
/dev/sda1: UUID="17f12d53-c3d7-4ab3-943e-a0a72366c9fa" TYPE="ext4"
```

После этого ФС можно монтировать по UUID:

```bash
mount UUID=17f12d53-c3d7-4ab3-943e-a0a72366c9fa /home/extra
```

### Почему UUID полезнее имени устройства?

Имя:

```text
/dev/sda1
```

определяется расположением/порядком обнаружения устройства.

UUID является свойством самой файловой системы:

```text
/dev/sda1 ───────┐
                 ├──► UUID=...
/dev/sdb1 ───────┘
```

Поэтому UUID особенно удобен для автоматического монтирования через `/etc/fstab`.

Для FAT могут использоваться собственные идентификаторы тома. UUID файловой системы также можно изменить, например после клонирования ФС, чтобы отличить копию от оригинала.

После разбиения диска на разделы на них создают файловую систему. Создание ФС выполняется в пользовательском пространстве, поскольку программа может напрямую обращаться к блочному устройству.

### `mkfs`

`mkfs` — универсальный интерфейс для программ создания конкретных файловых систем:

```bash
mkfs -t ext4 /dev/sda2
```

Фактически команда вызывает специализированную программу:

```text
mkfs
 └── mkfs.ext4
       └── mke2fs
```

Для разных ФС существуют свои программы:

```text
mkfs.ext4 → mke2fs
mkfs.vfat → mkdosfs
mkfs.ntfs → mkntfs
```

Поэтому при отсутствии `mkfs.ext4` стоит искать соответствующую специализированную утилиту.

### Суперблок

При создании ФС `mkfs` создаёт **суперблок** — ключевую структуру верхнего уровня файловой системы. В нём хранится важная информация, необходимая для работы с ФС.

Для защиты от повреждения создаются резервные копии суперблока. Их номера полезно сохранить: они могут понадобиться для восстановления:

```bash
fsck -b <номер_резервного_суперблока>
```

### Важно

Создание файловой системы уничтожает существующую файловую систему и её данные. Поэтому `mkfs` применяют только при создании новой ФС или когда старые данные можно удалить.

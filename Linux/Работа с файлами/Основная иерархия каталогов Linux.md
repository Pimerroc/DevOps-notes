The following directories, or symbolic links to directories, are required in /.
 Directory	Description
- bin  Essential command binaries
- boot 	Static files of the boot loader
- dev	 Device files
- etc	 Host-specific system configuration
- lib	 Essential shared libraries and kernel modules
- media 	Mount point for removable media
- mnt 	Mount point for mounting a filesystem temporarily
- opt 	Add-on application software packages
- run 	Data relevant to running processess
- sbin	Essential system binariess
- srv 	Data for services provided by this systems
- tmp 	Temporary filess
- usr 	Secondary hierarchys
- var 	Variable data
### Specific Options

	The following directories, or symbolic links to directories, must be in /, if the corresponding subsystem is installed:

Directory	Description
- home	User home directories (optional)s
-  `lib<qual>`	Alternate format essential shared libraries (optional)s
 - root	Home directory for the root user (optional)

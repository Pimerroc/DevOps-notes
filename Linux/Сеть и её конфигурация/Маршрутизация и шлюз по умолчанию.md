## Зачем нужна маршрутизация

IP-адрес позволяет идентифицировать хост.

Но перед отправкой пакета система должна определить:

```
куда физически или через какой интерфейс
нужно отправить пакет
```

Для этого используется **маршрутизация**.

---

## Таблица маршрутизации

Ядро Linux хранит таблицу маршрутизации.

Её можно представить следующим образом:

```
Пакет
  │
  ▼
IP-адрес назначения
  │
  ▼
Таблица маршрутизации ядра
  │
  ▼
Выбор маршрута
  │
  ├── непосредственно через интерфейс
  │
  └── через другой хост / маршрутизатор
```

Таблица маршрутизации определяет, как системе отправлять пакеты в различные сети.

---

## Маршрут к локальной подсети

Если IP-адрес назначения находится в той же подсети, что и отправляющий хост, пакет может быть отправлен непосредственно в локальную сеть.

Например:

```
Хост A
  │
  └──── LAN ────> Хост Б
```

Маршрутизатор для такой передачи может не потребоваться.

---

## Шлюз по умолчанию

Если пакет должен попасть в сеть, для которой в таблице маршрутизации нет более конкретного маршрута, используется **шлюз по умолчанию** (`default gateway`).

Схема:

```
Хост
  │
  │ неизвестная / внешняя сеть
  ▼
Шлюз по умолчанию
  │
  ▼
Маршрутизатор
  │
  ▼
Другая сеть / Интернет
```

Маршрутизатор принимает пакет и затем определяет, куда его отправлять дальше.

---

## Главная идея

Маршрутизация работает как последовательность решений.

Хост не обязан знать полный путь до конечного компьютера.

Он должен знать:

```
какому следующему узлу
нужно передать пакет
```

После этого следующий маршрутизатор принимает решение о дальнейшей передаче.

Таким образом, сеть может состоять из множества связанных подсетей, а пакеты проходят через последовательность маршрутизаторов.

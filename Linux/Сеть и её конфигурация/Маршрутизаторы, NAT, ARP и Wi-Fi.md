## Возвращение к простой локальной сети

После изучения сетевых уровней книга возвращается к первоначальной модели LAN.

Далее рассматриваются:

- автоматическое получение конфигурации;
- маршрутизация;
- работа маршрутизатора;
- выбор IP-адресов для подсети;
- фильтрация нежелательного трафика.

---

## Маршрутизатор

Маршрутизатор соединяет разные сети.

Его задача заключается в передаче пакетов между подсетями.

У маршрутизатора есть интерфейсы, связанные с различными сетями.

Упрощённо:

```
LAN
 │
 ▼
Интерфейс маршрутизатора
 │
 ├── таблица маршрутизации
 │
 ▼
Другой интерфейс
 │
 ▼
WAN / другая сеть
```

# Частные IPv4-сети

Книга далее рассматривает использование частных сетей IPv4.

Такие сети взаимодействуют с более крупными сетями через маршрутизаторы.

---

# NAT

NAT означает:

```
Network Address Translation
```

— преобразование сетевых адресов.

В главе рассматривается маскарадинг IP-адресов.

Этот механизм связан с тем, как частная сеть может взаимодействовать с внешней сетью, несмотря на особенности частных IPv4-адресов.

---

# ARP

На сетевом уровне хост работает с IP-адресами.

Однако на локальном физическом уровне необходимо знать аппаратный адрес устройства.

Для IPv4 используется:

```
ARP
Address Resolution Protocol
```

ARP позволяет определить аппаратный адрес устройства, связанный с IP-адресом в локальной сети.

Упрощённо:

```
IP-адрес
   │
   ▼
ARP
   │
   ▼
MAC-адрес
```

Система хранит соответствующую информацию в кэше.

---

# NDP в IPv6

В IPv6 используется другой механизм:

```
NDP
Neighbor Discovery Protocol
```

Он выполняет функции, связанные с обнаружением соседних устройств в локальной сети.

В книге упоминаются два типа сообщений:

- `Neighbor Solicitation`;
- `Neighbor Advertisement`.

# Wi-Fi

С точки зрения сетевого уровня Wi-Fi и проводной Ethernet во многом похожи.

Беспроводные устройства:

- имеют MAC-адреса;
- используют кадры Ethernet;
- могут управляться ядром Linux как сетевые интерфейсы.

Поэтому:

```
Сетевой уровень и выше
```

для проводной и беспроводной сети в основном одинаковы.

Основные отличия находятся на физическом уровне.

---

## Дополнительные компоненты Wi-Fi

Беспроводная сеть включает:

### Детали передачи

Например:

- радиочастоты.

### Сетевая идентификация

Используется:

```
SSID
Service Set Identifier
```

Это имя беспроводной сети.

### Управление

Большинство Wi-Fi-сетей используют точки доступа.

Точка доступа часто выступает мостом между:

```
беспроводной сетью
        │
        ▼
проводной сетью
```

### Аутентификация

Сеть может требовать:

- пароль;
- другой ключ аутентификации.

### Шифрование

Трафик, передаваемый по радиоволнам, обычно необходимо шифровать.

## `iw`

Для просмотра и изменения параметров беспроводного устройства используется:

```
iw
```

Например:

```
iw dev wlp1s0 scan
```

сканирует доступные беспроводные сети.

```
iw dev wlp1s0 link
```

показывает сведения о текущем беспроводном подключении.

Для незащищённой сети:

```
iw wlp1s0 connect network_name
```

---

## Безопасность Wi-Fi

Для большинства современных схем безопасности Linux использует:

```
wpa_supplicant
```

Он управляет:

- аутентификацией;
- шифрованием.

Поддерживаются WPA2 и WPA3.

Книга подчёркивает, что ручная настройка Wi-Fi может быть сложной:

```
iw
+
wpa_supplicant
+
сетевая конфигурация
```

Именно поэтому менеджеры сети, например NetworkManager, значительно упрощают настройку, управляя правильной последовательностью действий и необходимой конфигурацией.

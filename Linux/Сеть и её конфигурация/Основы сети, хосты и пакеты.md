## Что такое сеть

Сеть — это способ соединения компьютеров и передачи данных между ними.

При изучении сети возникают два фундаментальных вопроса:

1. **Как компьютер, отправляющий данные, определяет, куда их отправлять?**
2. **Как конечный компьютер определяет, что полученные данные предназначены именно ему?**

Для решения этих задач сеть использует набор компонентов. Каждый из них отвечает за определённую часть процесса передачи, получения и идентификации данных.

Эти компоненты объединяются в **сетевые уровни** (`network layers`), расположенные друг над другом и образующие целостную систему.

## Простая локальная сеть

Типичная домашняя или небольшая офисная сеть может быть представлена следующим образом:

В такой сети:

- компьютеры называются **хостами** (`hosts`);
- несколько хостов образуют локальную сеть — **LAN** (`Local Area Network`);
- один из узлов является **маршрутизатором** (`router`);
- маршрутизатор соединяет локальную сеть с интернетом.

В примере книги хосты и маршрутизатор находятся в одной локальной сети.

Подключения внутри LAN могут быть:

- проводными;
- беспроводными.

Строгого определения локальной сети нет, однако машины LAN обычно:

- физически расположены близко друг к другу;
- имеют похожую конфигурацию;
- обладают похожими правами доступа.

## LAN и WAN

Маршрутизатор имеет соединение с интернетом.

Такое соединение называется:

- **восходящим каналом** (`uplink`);
- или подключением к глобальной сети — **WAN** (`Wide Area Network`).

Таким образом:

```
Хосты
  │
  ▼
LAN
  │
  ▼
Маршрутизатор
  │
  ▼
WAN / Интернет
```

Маршрутизатор подключён одновременно:

- к локальной сети;
- к другой сети — интернету.

Именно поэтому компьютеры локальной сети могут получать доступ к интернету через маршрутизатор.

# Пакеты

Компьютер передаёт данные по сети не обязательно одним большим непрерывным объектом.

Данные передаются небольшими порциями, называемыми **пакетами**.

Пакет состоит из двух основных частей:

```
┌───────────────────────────┐
│ Заголовок                 │
├───────────────────────────┤
│ Полезная нагрузка         │
└───────────────────────────┘
```

## Заголовок

Заголовок содержит идентифицирующую информацию, например:

- исходный хост;
- конечный хост;
- используемый базовый протокол.

## Полезная нагрузка

Полезная нагрузка (`payload`) — это фактические данные, которые хочет передать приложение.

Например:

- HTML;
- изображение;
- другие данные приложения.

---

## Почему используются пакеты

Разделение данных на небольшие блоки позволяет:

- нескольким хостам обмениваться данными одновременно;
- отправлять данные нескольким получателям;
- чередовать пакеты для разных пунктов назначения;
- облегчать обнаружение ошибок передачи;
- компенсировать ошибки передачи.

Операционная система самостоятельно выполняет большую часть преобразований между данными приложения и пакетами.

Поэтому обычно не нужно вручную заниматься разбиением данных на пакеты, но необходимо понимать, что пакеты являются основой работы сетевых уровней.

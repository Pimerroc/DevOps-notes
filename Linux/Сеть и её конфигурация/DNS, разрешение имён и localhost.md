## Зачем нужен DNS

Людям удобнее использовать имена:

```
example.com
```

Компьютерная сеть работает с IP-адресами.

Поэтому необходим процесс:

```
Имя хоста
    │
    ▼
Разрешение имени
    │
    ▼
IP-адрес
```

---

## `/etc/hosts`

Файл:

```
/etc/hosts
```

содержит локальные соответствия между:

```
IP-адрес
   ↕
имя хоста
```

Этот механизм особенно полезен:

- в небольших сетях;
- в ситуациях, когда DNS ещё недоступен;
- на ранних этапах работы системы.

Книга не рекомендует использовать `/etc/hosts` как большой список для замены DNS.

---

## `resolv.conf`

Конфигурация разрешения имён связана с:

```
/etc/resolv.conf
```

Этот файл содержит информацию, используемую системой для работы с DNS.

Современные механизмы управления сетью могут автоматически управлять этой конфигурацией.

---

## `/etc/nsswitch.conf`

Порядок поиска имён определяется системой конфигурации служб имён.

Например:

```
hosts: files dns
```

означает:

```
1. Проверить локальные файлы
2. Затем использовать DNS
```

То есть система сначала может проверить `/etc/hosts`, а затем обратиться к DNS.

# Localhost

`localhost` — это текущий компьютер.

Для работы с ним используется специальный интерфейс:

```
lo
```

Это **loopback interface** — интерфейс обратной петли.

IPv4-адрес:

```
127.0.0.1
```

IPv6-адрес:

```
::1
```

---

## Как работает loopback

Передача происходит внутри системы:

```
Процесс
   │
   ▼
Интерфейс lo
   │
   ▼
Ядро Linux
   │
   ▼
Данные обрабатываются как входящие
   │
   ▼
Локальный процесс
```

Таким образом, две программы на одном компьютере могут взаимодействовать друг с другом через сетевой стек.

---

## Диапазон IPv4 loopback

Loopback связан не только с одним адресом.

Интерфейс использует:

```
127.0.0.1/8
```

То есть адреса, начинающиеся с:

```
127
```

относятся к пространству обратной связи.

Например, в книге рассматривается:

```
127.0.0.53
```

который может использоваться `systemd-resolved`.

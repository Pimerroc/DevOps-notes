## Зачем нужен DHCP

В IPv4 хост может автоматически получать свою сетевую конфигурацию через:

```
DHCP
Dynamic Host Configuration Protocol
```

DHCP позволяет получить:

- IP-адрес;
- маску подсети;
- шлюз по умолчанию;
- DNS-серверы.

---

## Почему DHCP удобен

DHCP:

- избавляет администратора от ручного ввода параметров;
- помогает предотвращать конфликты IP-адресов;
- уменьшает последствия изменения сети.

DHCP настолько распространён, что сеть без DHCP встречается редко.

---

## Первоначальный запрос DHCP

Когда новый хост подключается к сети, он ещё не знает:

```
где находится DHCP-сервер
```

Поэтому первоначальный запрос передаётся широковещательно.

Схема:

```
Новый хост
    │
    │ DHCP broadcast
    ▼
Локальная физическая сеть
    │
    ▼
DHCP-сервер
```

В простой сети DHCP-сервером часто является сам маршрутизатор.

---

## Аренда адреса

Хост не обязательно получает IP-адрес навсегда.

Он запрашивает:

```
lease
аренду
```

Адрес предоставляется на определённый период времени.

После этого аренда может быть продлена.

---

## DHCP-клиенты Linux

В Linux традиционно используется:

```
dhclient
```

Например:

```
dhclient enp0s31f6
```

DHCP-клиент хранит информацию о:

- своём PID;
- полученных арендах.

В книге также отмечается, что DHCP-клиент встроен в:

```
systemd-networkd
```

# Менеджеры конфигурации сети

Настройка сети сложна ещё и потому, что элементы конфигурации существуют на разных сетевых уровнях.

В Linux разные инструменты обычно не обмениваются файлами конфигурации между собой напрямую, поскольку изменение конфигурации одним инструментом может нарушить работу другого.

Поэтому существуют разные системы управления сетью.

---

## NetworkManager

NetworkManager — это менеджер, который собирает информацию о сетевых устройствах и доступных подключениях, а затем пытается активировать подходящее подключение.

При запуске он:

1. собирает информацию о сетевых устройствах;
2. просматривает список подключений;
3. пытается активировать одно из них.

Для Ethernet и Wi-Fi NetworkManager выбирает подключения на основе доступности и ранее использовавшихся сетей.

После установления соединения он поддерживает его до тех пор, пока:

- соединение не будет потеряно;
- не появится более подходящая сеть;
- пользователь не изменит конфигурацию.

---

## Netplan

Netplan — это не столько самостоятельный менеджер сети.

Он представляет собой:

- унифицированный стандарт конфигурации;
- инструмент преобразования конфигурации для других менеджеров.

Netplan поддерживает:

```
NetworkManager
systemd-networkd
```

Файлы конфигурации:

```
YAML
```

располагаются в:

```
/etc/netplan
```

## Сетевой интерфейс

Linux взаимодействует с сетью через **сетевые интерфейсы**.

Интерфейс представляет точку подключения системы к сети.

Он может быть связан с:

- проводным устройством;
- беспроводным устройством;
- виртуальной сетевой конфигурацией.

У одного компьютера может быть несколько интерфейсов.

Каждый интерфейс может быть связан со своей сетью и иметь собственную конфигурацию.

---

## Настройка интерфейса

Настройка сети включает несколько независимых компонентов.

Например:

```
Интерфейс
    │
    ├── IP-адрес
    ├── подсеть
    ├── маршруты
    ├── шлюз
    └── DNS
```

Linux позволяет управлять этими параметрами отдельно.

---

## Ручная настройка

Сетевой интерфейс можно настраивать вручную.

Для этого используются инструменты, работающие с сетевыми структурами ядра.

Основные современные команды:

```
ip addr
```

и:

```
ip route
```

---

## Почему ручная настройка неудобна

Ручная настройка хорошо подходит для понимания сети и некоторых специализированных систем.

Однако современные сети динамичны.

Компьютер может:

```
одна сеть
   ↓
отключение
   ↓
другая сеть
   ↓
Wi-Fi
   ↓
Ethernet
```

При этом:

- IP-адрес может измениться;
- маршруты могут измениться;
- DNS-серверы могут измениться;
- шлюз может измениться.

Поэтому большинство современных систем используют автоматическую настройку.

---

# Конфигурация при загрузке

Исторически конфигурация сети часто активировалась при загрузке системы.

Однако современная сеть может изменяться уже после загрузки.

Например:

- подключение кабеля;
- отключение кабеля;
- появление Wi-Fi;
- исчезновение Wi-Fi;
- изменение доступных сетей.

Поэтому конфигурацией всё чаще управляют специальные менеджеры сети.

1. useradd -m max
2. passwd max (настроить пароль)
3. usermod -aG sudo(wheel) max (добавить sudo)
4. ssh-keygen -t rsa -N '' /etc/ssh/ssh_host_rsa_key
5. В виртуалке сделал проброс портов, (host- 127.0.0.1:22222,guest 0.0.0.0:22)
6. разкоментил hostkey, (PermitRootLogin no) запрет на root-login
   PasswordAuthentication yes -> no
   PublicKeyAuthentication (разкомитить) 
7. sshd -t (проверка конфигурационных файлов на sanity)
C помощью ufw :
8. sudo apt install ufw 
9. ufw enable
10. ufw default deny incoming
11. ufw allow 22/tcp 
12. ну и все по сути (ufw status verbose)
С помощью nftable:
13. [Официальный конфиг для серва](https://wiki.nftables.org/wiki-nftables/index.php/Simple_ruleset_for_a_server?utm_source=chatgpt.com)
14. Копипастим в /etc/nftable.conf, при необходимости меняем политику для портов (так как официальный конфиг и без того подходит, для тестового окружения пофиг)
15. sudo nft -c -f /etc/nftables.conf (проверить)
	sudo nft -f /etc/nftables.conf (применить)
16. systemctl enable nftables.service

(при создании юзера, можно указать дефолтную оболочку в виде -s /bin/bash к примеру в противном случае придется 
sudo chsh -s /bin/bash max)

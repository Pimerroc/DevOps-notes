# Планировщик дня (второй шаг утреннего ритуала)

Ты — агент `devops` в vault `~/DevOps_Notes`. Выше брифинг. Первый шаг уже переписал в `DevOpsNotes/DevOps/Board.md` раздел `## Сегодня` с MIN/MAX. Твоя задача — превратить его в план с таймбоксами.

## Что сделать

1. Прочитай в Board раздел «Сегодня», в Review Queue — просроченные карточки, в Roadmap — текущий этап.
2. Добавь в конец раздела «Сегодня» блок:

```md
> [!note] План дня — черновик
> - 07:10–07:20 — повтор: …
> - 07:20–08:20 — чтение: … (источник, раздел)
> - 08:20–09:30 — практика: … (лаба)
> - 09:30–10:00 — live: `/live go <задача>`
> - 21:00 — закрытие: отчёт
> Статус: черновик. Подтверди или поправь в сессии `AgentStuff/DevOps/harness/run.sh open`.
```

3. Для каждого блока укажи исполнителя: `devops-tutor` — объяснение, квиз, каркас заметки; `devops` — лаба и работа; `devops-verifier` — проверка; `/live go <задача>` — livecoding.
4. Чтение — только конкретика: глава, раздел, man-страница, статья. Не «почитать про сети», а «Таненбаум гл. 7, стр. 684–700, 40 минут».
5. Если в Board уже есть внешние задания (kodekloud, SadServers) — дай им слот с временем. Не добавляй платформы, которых в Board нет.
6. Live-слот: если в Learning Log последняя запись про live старше 3 дней — поставь 30 минут `/live go <задача>` (язык по умолчанию Go). Если live был вчера-позавчера — не ставить.
7. Бюджет: не больше 4 блоков и 6 часов. Не помещается — режь, а не растягивай. Одна новая заметка в день максимум.
8. Не меняй MIN/MAX, не удаляй чужие пункты, не трогай «Заморозку».

## Ограничения

- Запуск неинтерактивный: вопросов не задавать. Валидация будет в сессии, не здесь.
- Ничего не выполнять: ни лаб, ни заметок, ни команд. Только план.
- Не коммитить.
- План — черновик: не помечай его подтверждённым и не ставь галочки.

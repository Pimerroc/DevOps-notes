Тема: $ARGUMENTS

1. Диагностика: 2–3 открытых вопроса по теме. Без подсказок и без объяснения до ответов.
2. Объяснение по слоям: mental model → механика → команды → подводные камни. Источники — только реальные (`man`, официальные docs, книга); URL проверь.
3. Практика: одно задание с критерием успеха. Выполняет пользователь, ты сверяешь результат.
4. Каркас заметки из `Templates/DevOps Note.md`: 3–5 вопросов и 3–5 источников-кандидатов. Ответы не заполнять. Файл создаёшь только после явного подтверждения.
5. Заверши тремя строками: что понято, что осталось, следующий шаг.

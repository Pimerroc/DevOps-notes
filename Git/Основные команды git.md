# [Git Cheat Sheet](https://git-scm.com/cheat-sheet)

| Команда            | Основные ключи                                                                                                                                                                                                                                                                                           | Краткое описание                                                                                                                                                                                              |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `git init`         | -b \<branch name\> название изначальной ветки                                                                                                                                                                                                                                                            | Создает репозиторий отслеживаемый гитом                                                                                                                                                                       |
| `git clone <url>`  | `git clone <url> [<repo name>]`-- <br>чтобы клонировать репозиторий с определенным именем                                                                                                                                                                                                                | Клонирует репозиторий с удаленного сервера                                                                                                                                                                    |
| `git add \<file\>` | git add . (добавляет все файлы)                                                                                                                                                                                                                                                                          | Делает выбранный файл/файлы отслеживаемыми                                                                                                                                                                    |
| `git commit`       | -m "Message" создать коммит с сообщением Message<br>-a сделать все файлы отслеживаемыми прямо перед коммитом (аналог git add .)<br>--amend изменить последний коммит, не добавляя нового в историю изменений                                                                                             | Зафиксировать выбранные изменения и вернуть их к состоянию                                                                                                                                                    |
| `git push`         | git push \<origin или другой\> \<branchOnLocal\>:\<branchOnServer\> -- запушить ветку из локального репозитория в ветку сервера хранилища<br>git push \<origin или другой\> \<branch\> -- запушить в несуществующую на сервере ветку                                                                     | Передать изменения находящиеся в локальном репозитории и передать их на сервер (GitHub, GitLab, BitBucket)                                                                                                    |
| `git pull`         | git pull \<origin или другой\> \<branchOnServer\>:\<branchOnLocal\> -- получить данный с ветки branchOnServer и занести их в ветку branchOnLocal, если такой ветки нет, то она появится<br>git pull \<origin или другой\> \<branchOnServer\> -- получить данные с конкретной ветки на конкретном сервере | Команда аналогична последовательности команд `git fetch; (git merge/git rebase)`. Команда подгружает изменения в ветках на удаленных серверах и сливает их с текущей активной веткой (там где находится HEAD) |
| `git checkout`     | -b создает новую ветку и сразу переходит в нее                                                                                                                                                                                                                                                           | Команда используется для перемещения между ветками                                                                                                                                                            |
| `git cherry-pick`  | `git cherry-pick <commit hash> .. <commit hash №n>`                                                                                                                                                                                                                                                      | Команда берет коммиты в той очередности в который они даны и присоединяет их к текущему HEAD. Коммиты не должны быть предками текущей HEAD.                                                                   |
| `git rebase`       | -i                                                                                                                                                                                                                                                                                                       |                                                                                                                                                                                                               |

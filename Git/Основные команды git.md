# [Git Cheat Sheet](https://git-scm.com/cheat-sheet)

| Команда                                                       | Основные ключи                                                                                                                                                                                                                                                                                           | Краткое описание                                                                                                                                                                                              |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`git init`](https://git-scm.com/docs/git-init)               | -b \<branch name\> название изначальной ветки                                                                                                                                                                                                                                                            | Создает репозиторий отслеживаемый гитом                                                                                                                                                                       |
| [`git clone <url>`](https://git-scm.com/docs/git-clone)       | `git clone <url> [<repo name>]`-- <br>чтобы клонировать репозиторий с определенным именем                                                                                                                                                                                                                | Клонирует репозиторий с удаленного сервера                                                                                                                                                                    |
| [`git add <file>`](https://git-scm.com/docs/git-add)          | git add . (добавляет все файлы)                                                                                                                                                                                                                                                                          | Делает выбранный файл/файлы отслеживаемыми                                                                                                                                                                    |
| [`git commit`](https://git-scm.com/docs/git-commit)           | -m "Message" создать коммит с сообщением Message<br>-a сделать все файлы отслеживаемыми прямо перед коммитом (аналог git add .)<br>--amend изменить последний коммит, не добавляя нового в историю изменений                                                                                             | Зафиксировать выбранные изменения и вернуть их к состоянию                                                                                                                                                    |
| [`git push`](https://git-scm.com/docs/git-push)               | git push \<origin или другой\> \<branchOnLocal\>:\<branchOnServer\> -- запушить ветку из локального репозитория в ветку сервера хранилища<br>git push \<origin или другой\> \<branch\> -- запушить в несуществующую на сервере ветку                                                                     | Передать изменения находящиеся в локальном репозитории и передать их на сервер (GitHub, GitLab, BitBucket)                                                                                                    |
| [`git pull`](https://git-scm.com/docs/git-pull)               | git pull \<origin или другой\> \<branchOnServer\>:\<branchOnLocal\> -- получить данный с ветки branchOnServer и занести их в ветку branchOnLocal, если такой ветки нет, то она появится<br>git pull \<origin или другой\> \<branchOnServer\> -- получить данные с конкретной ветки на конкретном сервере | Команда аналогична последовательности команд `git fetch; (git merge/git rebase)`. Команда подгружает изменения в ветках на удаленных серверах и сливает их с текущей активной веткой (там где находится HEAD) |
| [`git checkout`](https://git-scm.com/docs/git-checkout)       | -b создает новую ветку и сразу переходит в нее                                                                                                                                                                                                                                                           | Команда используется для перемещения между ветками                                                                                                                                                            |
| [`git cherry-pick`](https://git-scm.com/docs/git-cherry-pick) | `git cherry-pick <commit hash> .. <commit hash №n>`                                                                                                                                                                                                                                                      | Команда берет коммиты в той очередности в который они даны и присоединяет их к текущему HEAD. Коммиты не должны быть предками текущей HEAD.                                                                   |
| [`git rebase`](https://git-scm.com/docs/git-rebase)           | -i -- интерактивно позволяет менять очередь коммитов                                                                                                                                                                                                                                                     | Перемещает все коммиты с другой ветки на текущую, не создавая при этом новый коммит                                                                                                                           |
| [`git merge`](https://git-scm.com/docs/git-rebase)            | --squash -- сливает все коммиты ветки вооедино позволяя повторно закоммитить                                                                                                                                                                                                                             | Сливает все коммиты текущей ветки с указанной, создавая при этом новый коммит                                                                                                                                 |
| [`git reset`](https://git-scm.com/docs/git-reset)             | `git reset HEAD^` -- возвращает состояние предпоследнего коммита, удаляя при этом текущий коммит                                                                                                                                                                                                         | Команда только возвращает состояние HEAD в прежнее.                                                                                                                                                           |
| [`git restore`](https://git-scm.com/docs/git-restore)         | `git restore --staged <file>` -- unstage выбранного файла<br>`git restore <file>` -- полностью удаляет изменения в выбранном файле<br>`git revert HEAD^`  возвращает состояние предыдущего коммита для всех, создавая при этом новый                                                                     | Команда либо возвращает назад коммит и создавая при этом новый, либо возвращает предыдущее состояние файла.                                                                                                   |

Также могут понадобиться [`git log`](https://git-scm.com/docs/git-log), [`git show`](https://git-scm.com/docs/git-show), [`git diff`](https://git-scm.com/docs/git-diff) , [`git describe`](https://git-scm.com/docs/git-describe), [`git status`](https://git-scm.com/docs/git-status), [`git remote`](https://git-scm.com/docs/git-remote)
